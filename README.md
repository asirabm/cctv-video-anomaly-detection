# cctv-video-anomaly-detection
Deep learning based CCTV video anomaly detection using CNN and LSTM.
## Project Description
The purpose of this project is developing a deep learning system that detect unusual activities in CCTV videos.
The proposed this system, first convert videos into frames and extract useful information using Convolutional Neural Network (CNN). Next use an LSTM to learn pattern over time.
The main pipeline is:
Video Frames -- CNN-- LSTM -- Score for unusual activity 
## Dataset
The main dataset planned for this project is UCF-crime date set. This dataset contains normal activities and unusual activities. The dataset files will not be stored in this GitHub repository because of its size.
